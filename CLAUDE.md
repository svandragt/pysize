## What this is

pysize is a bundlephobia-style size explorer for PyPI packages: enter a requirement
(`requests`, `headroom-ai[all]`, `django>=5`) and get the install size as the wheel
plus the full deduplicated dependency tree. It resolves entirely against the public
PyPI JSON API — nothing is installed. It's a proof of concept, deployed to a personal
VPS behind nginx.

## Commands

```bash
make run            # run locally on http://127.0.0.1:8731 (= uv run main.py)
make verify N=10    # diff resolution against `uv pip compile` on N random popular pkgs
make deploy         # ansible redeploy (prompts for sudo password via -K)
make logs           # tail the systemd service logs on the server
make clean          # delete the local sqlite cache
make help           # list targets
```

Dependencies are declared in a PEP 723 inline header in `main.py`; `uv run` reads them —
there is no `requirements.txt` or `pyproject.toml`. Run the server with `uv run main.py`
(it self-hosts via `uvicorn.run()`), **not** `uv run uvicorn main:app` (uvicorn isn't on PATH).

There is no test suite. `verify.py` is the correctness check — it compares the resolved
dependency *set* against a real resolver (`uv`). Check a specific package with
`uv run verify.py flask boto3`.

## Architecture

Two files do the work: `main.py` (FastAPI backend + resolver + cache) and `index.html`
(single-page frontend served by the `/` route). `main.py` is read top-to-bottom as
cache → fetch helpers → `resolve()` → `/api/size`.

**Resolver (`resolve()`)** — a fixpoint over the dependency graph, not simple recursion.
The non-obvious invariants that make it correct:
- Each package is tracked **once** by canonical name, so the total is a true deduplicated
  size. The frontend shows a flat size-sorted list, not a tree.
- Per package it accumulates the **union of extras** and the **intersection of version
  specifiers**, then picks the highest satisfying version (`best_version()`).
- The top-level PyPI JSON only carries the *latest* version's `requires_dist`, so to honor
  specifiers it fetches the **per-version** endpoint for the version actually chosen.
- A node is re-expanded only when its chosen version or extra set grows. Because extras
  only accumulate and specifiers only tighten, this terminates — and self-referential
  extras like `pkg[all]` → `pkg[eval]` resolve cleanly instead of being cut as cycles.
  (This was the bug that made `headroom-ai[all]` report 77 MB instead of ~2.9 GB.)

**Markers** are evaluated against a fixed `TARGET_PYTHON` ("3.12"), never the host
interpreter — otherwise `python_version`-gated deps appear/vanish based on what runs the
server. Change `TARGET_PYTHON` to resolve for a different Python; `verify.py` must use the
same target to compare fairly.

**Caching (`Cache` class)** — two tiers, both 1h TTL: a size-bounded in-memory LRU
(32 MB of JSON text) over a SQLite file (`PYSIZE_CACHE` env, defaults next to `main.py`;
gitignored). SQLite bounds RAM (a single botocore index is ~3 MB JSON) and survives
restarts. *Both* PyPI responses and full resolution results are cached (resolution keyed
`resolve:name[extras]specifier`). SQLite I/O runs via `asyncio.to_thread`. A shared
`httpx.AsyncClient` (lifespan-managed) plus a concurrency semaphore (`MAX_CONCURRENCY`)
keep PyPI traffic polite; single-flight de-dup shares concurrent identical fetches.

Abuse guards: `MAX_PACKAGES` caps graph size (sets a `truncated` flag), `RESOLVE_TIMEOUT`
bounds the whole request.

## Deployment

`ansible/` deploys pysize as a hardened systemd service (uvicorn on `127.0.0.1:8731`)
behind a single nginx reverse-proxy vhost — existing nginx/PHP sites are untouched. uv
builds a venv, code is pulled from this git repo, TLS via certbot webroot (gated so it's
idempotent). See `ansible/README.md`.

**This is a public repo.** Per-instance config (`ansible/vars.yml`, `ansible/inventory.ini`)
is gitignored — the tracked templates are `*.example.*`. Never commit real domains, IPs,
or emails; put them only in the gitignored files.

## Local server gotcha

The server binds `127.0.0.1:8731`. Before restarting, `TaskStop` the running background
task (or `kill $(lsof -ti tcp:8731)`) or it errors `address already in use`. Poll readiness
with a short `curl` loop against `/`.
